# Raghav Anand · Portfolio

**My personal website: who I am, the cybersecurity projects I have built, where I have studied and worked, and my résumé.**

Why it exists: one page that shows my work in identity and access management, application security, DevSecOps and applied AI security.

**Live: [raghavanand-prog.github.io/portfolio](https://raghavanand-prog.github.io/portfolio/)**

## How to run

It is a static site with no build step: open `index.html` in any browser.

## What's inside

| File | What it is |
| --- | --- |
| `index.html` | The whole site: page, styles and scripts |
| `anime.umd.min.js` | The animation library the page uses, kept in the repository |
| `Raghav_Anand_Resume.pdf` | My résumé |
