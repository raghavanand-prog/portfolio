The rules

Eight rules I build by. Every one of them shows up somewhere in the work below.

  1. 1st

    You do not ship what you can’t defend.

  2. 2nd

    You DO NOT ship what you can’t defend.

  3. 3rd

    If a scan fails, the deploy is over. If a scanner is missing, the deploy is over too.

  4. 4th

    One role per actor. Least privilege, every permission written down.

  5. 5th

    No record is silently dropped. Accept, warn, quarantine or reject.

  6. 6th

    Mask it on the server. The browser never sees what the role can’t.

  7. 7th

    Rotate the token on every use. A replayed token ends the session.

  8. 8th

    If it’s your first deploy, you write the test first.

Homework assignment 01

Secure CI/CD Pipeline

PARA CI/CDSecurity-gated delivery pipelineCodeBuild · Terraform · ECS Fargate5 gates. Fails closed.

A pipeline that fights every deploy, and a failed scan always wins.

Five gates run in AWS CodeBuild before CodePipeline may deploy to ECS Fargate. If any gate fails, or a scanner is missing or crashes, the release stays down. Built on 8 Terraform modules with least-privilege IAM, and deployed to a real AWS account where 8 production incidents were root-caused and documented.

  • SASTSemgrep on the application code
  • SCAnpm audit + OWASP Dependency-Check
  • SecretsGitleaks across the full git history
  • IaCCheckov on the Terraform
  • ImageTrivy on the final container

    Customer360

    CUSTOMER360Unified customer data platformPySpark · FastAPI · PostgreSQL · React0.994 precision

    Four records. One person. The twist is the product.

    Customer360 ingests CRM, app, loyalty and support records, checks their quality, and works out which records belong to the same person. The single profile is served through an API that enforces roles and masks personal data on the server.

    • Ingest9 source files across 3 formats, processed with PySpark
    • Quality38 rules in 6 dimensions; no record silently dropped
    • Identity0.994 precision, 0.857 recall against ground truth
    • AccessRefresh-token reuse detection, Argon2id, 4-role RBAC
    • PrivacyEmail and phone masked server-side for lower roles

    Homework assignment 03

    StegoShield

    STEGOSHIELDSteganography & steganalysis platformPython · scikit-learn · Flask49 features

    Tyler spliced single frames into family films. StegoShield looks for what’s spliced into images.

    Steganography hides a payload in an image’s pixels, invisible to the eye. StegoShield embeds messages with LSB steganography, then uses a Random Forest over 49 statistical features to flag images that are probably carrying hidden data.

    • EmbedLSB encoding with a SHA-256-checked payload
    • DetectRandom Forest, leak-safe split by source image
    • HardenUpload sniffing, size caps; a reflected XSS found and fixed
