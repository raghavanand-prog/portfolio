DevSecOps · AWS · 2026

Secure CI/CD Pipeline

A pipeline where a security finding actually blocks the deploy — not just flags it.

Most CI/CD projects stop at “it builds and deploys.” This one treats a failing scan as a failing build. Five gates run in AWS CodeBuild before CodePipeline is allowed to deploy to ECS Fargate.

  • SASTSemgrep for code-level vulnerabilities
  • SCAnpm audit + OWASP Dependency-Check for known CVEs
  • SecretsGitleaks, so credentials never reach a commit
  • IaCCheckov on the Terraform itself
  • ImageTrivy on the final container image
Auth layer

Short-lived, stateless JWTs for access, paired with a server-tracked refresh token that rotates on every use — so a compromised session is actually revocable. A live dashboard shows real rate-limit headers and fires invalid-token requests you can watch get rejected.

Applied AI · Steganalysis · 2026 – Present

StegoShield

Machine learning that finds data hidden inside ordinary-looking images.

Steganography hides a payload inside an image’s pixels — invisible to the eye, which makes it a quiet channel for data exfiltration and malware delivery.

StegoShield is my AI steganography & steganalysis platform: it analyses images and classifies them as clean or carrying embedded hidden data.

  • DetectFlags images that are likely carrying an embedded payload
  • ClassifySeparates clean carriers from stego images with ML models
  • AnalyseTreats images as an attack surface, not just media
