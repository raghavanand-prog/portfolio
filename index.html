01 · Data platform · AppSec · 2026

Customer360

Scattered customer records, resolved into one profile and locked down by role.

Customer360 ingests records from a CRM, an app, a loyalty programme and support, checks their quality, works out which belong to the same person, and serves one profile through a role-secured API.

  • Ingest9 source files across 3 formats, processed with PySpark
  • Quality38 rules in 6 dimensions; no record silently dropped
  • Identity0.994 precision, 0.857 recall against ground truth
  • AccessRefresh-token reuse detection, Argon2id, 4-role RBAC
  • PrivacyEmail and phone masked server-side for lower roles

02 · DevSecOps · AWS · 2026

Secure CI/CD Pipeline

A pipeline where a security finding blocks the deploy instead of just flagging it.

Five gates run in AWS CodeBuild before CodePipeline may deploy to ECS Fargate. The gate fails closed: a scanner that is missing or crashes blocks the release too.

  • SASTSemgrep for code-level vulnerabilities
  • SCAnpm audit + OWASP Dependency-Check
  • SecretsGitleaks across the full git history
  • IaCCheckov on the Terraform
  • ImageTrivy on the final container

    03 · Applied AI · Steganalysis · 2026

    StegoShield

    Hiding data inside ordinary images, and using machine learning to find it.

    Steganography hides a payload in an image’s pixels, invisible to the eye. StegoShield embeds messages with LSB steganography and classifies images as clean or carrying hidden data.

    • EmbedLSB encoding with a SHA-256-checked payload
    • DetectRandom Forest over 49 statistical features, leak-safe split
    • HardenUpload sniffing, size caps; a reflected XSS found and fixed
